# Доска проекта

## Представление Board

Используются статусы:

- Backlog
- Ready
- In Progress
- Review
- Blocked
- Done

## Поля

| Поле | Значения |
|---|---|
| Status | Backlog / Ready / In Progress / Review / Blocked / Done |
| Assignee | участник команды |
| Area | Frontend / Backend / DB / Scheduler / DevOps / Docs |
| Priority | High / Medium / Low |
| Checkpoint | недельная контрольная дата |
| Size | S / M / L |
| FS | связанные требования FS |
| HLD | связанные разделы HLD |
| Blocked by | ссылка на блокирующую задачу |

## Размер задачи

**S** — небольшое изолированное изменение.

**M** — законченная небольшая функция.

**L** — несколько тесно связанных частей одной функции.

Задача размера XL должна быть разбита.

## Правила движения

**Backlog** — работа известна, но ещё не готова к старту.

**Ready** — требования и зависимости определены, задачу можно брать.

**In Progress** — работа реально начата. На одного участника желательно не более двух активных задач.

**Review** — открыт Pull Request и ожидается review.

**Blocked** — задачу невозможно продолжать без внешнего результата. Причина блокировки указывается в карточке.

**Done** — Pull Request в main и выполнен Definition of Done.

## Еженедельный созвон

Раз в неделю в течение 30–60 минут команда проходит доску в порядке:

1. Review
2. Blocked
3. In Progress
4. Ready

Обсуждаются конкретные результаты, попавшие в main, блокеры и задачи до следующей контрольной точки.
